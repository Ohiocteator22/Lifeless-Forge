# WHAT IS THIS?
the Explorer integration feature of Forge is not native, it can be installed and uninstalled using the registry files provided below
no they are not viruses, and no they will not destroy your PC, 
if you are unsure, the file are open-access so you can ask any Ai to check what it does

REQUIRES- FORGE.EXE TO EXIST IN IN THE REPOSITORY ARCHIVE
IF FORGE.EXE IS LOCATED IN ANY OTHER FOLDER CHANGE THE REGISTRY EDITOR

## TO USE THE REGISTRY FILES-
DOWNLOAD THE FILE PROVIDED BELOW, GOTO THE "dist/" folder and run the .reg file
YOU **NEED** TO HAVE FORGE.EXE IN THE dist/ Folder alongside the .reg files or it will NOT WORK

## STEP BY STEP
- Download Forge from the releases page, this feature is compatible with v1.1.8 and above
- Extract the .tar.xz file via forge
- it will extract to a folder, enter the folder, and goto
```
Lifeless-Forge-main/Lifeless-Forge-main/dist
```
- locate the Forge.exe and two registry files
- Run install_context.reg
- shift + right click on any file and find "Forge" in the context menu
- if it doesnt appear run the uninstall_context.reg

-Lifeless
